Shell 项目

服务器整机检测与老化测试 Shell 脚本

x86 服务器硬件预检、诊断与 burn-in 验证，双脚本分工覆盖全链路测试流程

项目简介

本套件包含两个 Bash 脚本：MHCtest.sh负责整机普通检测（CPU/GPU/风扇/电源/硬盘SMART/网卡打流/PCIe/CMOS预检、dmesg 与 BMC SEL 日志巡检、硬盘指示灯点灯测试、USB 速率检测），MHC.sh负责压力老化测试（FIO 磁盘压测、stress-ng CPU 烤机、memtester 内存压测、gpu-burn 双精度计算、NCCL 多卡带宽），并附带后台温度/功耗监控与 CSV 曲线记录。全程一键运行，无需额外依赖，支持非交互自动化模式，可在 CentOS、Ubuntu、RHEL 等主流 x86 Linux 发行版上直接执行。

核心功能

  • 依赖工具批量预检 + 自动安装（apt/yum/dnf 通用）
  • CPU 温度、GPU 状态、风扇转速、电源模块预检
  • 硬盘 SMART 健康度与错误日志采集
  • iperf3 双向打流（支持对端打流与全自动本机自回环两种模式）
  • dmesg 内核日志与 BMC SEL 日志关键字扫描（error/warning）
  • 硬盘指示灯三色人工确认测试（蓝灯/橙灯/熄灭）
  • USB 总线拓扑与速率人工判定
  • FIO 顺序读写压测、stress-ng CPU 烤机、memtester 内存压力
  • gpu-burn 双精度 GPU 计算稳定性验证
  • NCCL All-Reduce 多卡带宽测试（≥2 张 GPU 自动执行）
  • 后台实时监控：CPU 温度、整机功耗、GPU 温度与利用率，输出 CSV 曲线数据
  • 完整时间校验（系统与 BMC 偏差限 60 秒）、自动化工号与 SN 录入
  • Ctrl+C 安全退出处理（终止后台进程、清理临时文件）
