wtest · x86 server acceptance toolkit

服务器整机验收测试脚本集

面向 x86 服务器整机验收的 Shell 工具集。覆盖硬件预检、日志会话控制、部件检测、网络打流与老化压测全流程，统一判定口径，可直接在 Ubuntu / CentOS / RHEL 上执行。

设计要点

这套脚本不是零散命令的堆叠，而是按验收流程设计的工具链。

统一判定口径

全集采用 PASS / FAIL / Pending 三态判定，配 0 / 1 / 2 退出码，可直接接入上层流水线。

不落盘，不改变被测系统

绝大多数脚本运行时不写任何文件、不修改系统状态，验收过程本身不引入新的变量。

依赖自愈

启动即做依赖工具预检，缺失时按 apt / dnf / yum 自动安装，减少现场准备成本。

跨发行版可用

在 Ubuntu、CentOS、RHEL 等主流 Linux 发行版上可直接执行；GPU 相关项在无卡机器上自动跳过。

使用方式

在脚本所在目录执行。SN 自动从 BMC FRU 读取，无需手动输入。

# 整机硬件预检（一次跑完所有在位与状态检查）
sudo bash test.sh

# 开启一次验收记录会话，此后终端所有输出同时写入台账
sudo ./log.sh

# 老化压测与电源循环需在会话外单独执行
sudo bash lhtest.sh
sudo bash dcpower.sh

验证状态说明

关于验证状态，请先看这条。

本套脚本中有小部分是在开发阶段没有测试环境的情况下完成的，尚未经过实机验证。这些脚本的逻辑与阈值虽已按公开规格与验收 SOP 仔细推敲，但仍可能存在与实际机型 / BMC / 驱动版本不符之处。

使用前建议：先核对脚本内的阈值与判定口径是否符合本次验收要求，并尽量先在非生产环境试跑一遍。脚本头部注释里凡是有「设计说明」一节的，都已写明该处为什么这么写、以及已知的取舍与限制，可作为核对依据。
本套脚本持续更新、持续优化，并持续新增测试项目。若发现脚本与文档描述不一致，以脚本源码为准。
